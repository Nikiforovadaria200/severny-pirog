# Школьный буфет «Северный пирог»

Учебный одностраничный сайт школьного буфета.

🔗 **Посмотреть проект:** https://nikiforovadaria200.github.io/severny-pirog/

## Стек технологий
*   HTML
*   CSS
*   JavaScript (без фреймворков и сборщиков)

## Что умеет сайт
*   Рисует меню из шести позиций на основе массива данных
*   Фильтрует блюда на сладкие и солёные, сортирует по цене
*   Показывает состав пирога в модальном окне
*   Считает общую сумму выбранных позиций
*   Переключает тёмную тему и запоминает выбор пользователя
*   Отображает картинку `pie.svg` через относительный путь

## Роль ИИ в проекте
*   Картинка `pie.svg` подготовлена по образцу из рабочего листа, имена файлов и пути проверены вручную
*   Текст этого README сформулирован с помощью ИИ и сверен с реальными возможностями сайта
